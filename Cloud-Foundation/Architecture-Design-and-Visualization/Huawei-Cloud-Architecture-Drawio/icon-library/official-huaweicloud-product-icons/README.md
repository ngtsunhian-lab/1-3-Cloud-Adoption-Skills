# Huawei Cloud Official Product Icons

This folder contains Huawei Cloud product icons collected from the public Huawei Cloud product pages on 2026-05-20.

Sources:

- https://www.huaweicloud.com/intl/en-us/product/
- https://www.huaweicloud.com/intl/zh-cn/product/
- https://www.huaweicloud.com/product/

Contents:

- `images/`: downloaded PNG/SVG product icons from Huawei Cloud CDN.
- `drawio/Huawei Cloud Official Product Icons.xml`: one diagrams.net / Draw.io library containing all collected official product icons.
- `drawio/Huawei Cloud *.xml`: category-specific Draw.io libraries.
- `official-icons-manifest.csv`: spreadsheet-friendly manifest.
- `official-icons-manifest.json`: structured manifest.
- `official-summary.json`: count summary.

Import in Draw.io with `File > Open Library...`, then select either the all-in-one XML or one category XML.
