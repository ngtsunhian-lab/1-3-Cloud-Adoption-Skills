# Architecture Design and Visualization

This use case focuses on reusable architecture-design assets for Huawei Cloud adoption work, including diagram generation, icon libraries, reference architectures, and review-ready visual outputs.

## Typical Skill Areas

- Architecture diagram generation
- Huawei Cloud icon library management
- Solution-design visualization
- Disaster recovery and multi-region topology diagrams
- Resource inventory alignment with architecture diagrams

## Expected Outputs

- Reusable diagram-generation skills
- `.drawio` / diagrams.net architecture files
- Architecture JSON source files
- Huawei Cloud product icon libraries
- Resource inventory exports

## Skills

- [Huawei Cloud Architecture Draw.io](./Huawei-Cloud-Architecture-Drawio/README.md): Generate Huawei Cloud architecture diagrams in draw.io / diagrams.net format with bundled official Huawei Cloud product icons, validation scripts, and sample architectures.
